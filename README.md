# Seven-Segment Data Dashboard Simulator

## Project Overview

This project is a Python-based Seven-Segment Data Dashboard Simulator.

It demonstrates how digital data can be represented using a seven-segment display and provides fault simulation for individual segments.

## Features

- Seven-segment display mapping for digits 0 to 9
- Interactive Streamlit dashboard
- Segment ON/OFF status
- Synthetic test data
- 10 normal test cases
- 5 fault/edge test cases
- Fault detection and status display

## Technologies Used

- Python
- Streamlit
- NumPy
- Pandas
- Matplotlib

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

python -m streamlit run dashboard.py

4. Open the Local URL shown in the terminal.

## Test Cases

The project contains:

- 10 normal test cases
- 5 fault/edge cases

## Conclusion

The simulator demonstrates seven-segment digital logic, data representation, interactive visualization, and basic fault detection using Python.
